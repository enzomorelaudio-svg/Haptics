AHAP Haptic Editor

Draw Core Haptics patterns, then export them as .ahap JSON. Height = intensity, colour = sharpness (softsharp).

Tap: click to add a tap. Buzz: drag to draw a continuous event. Drag anything to move it; drag a buzz’s right edge to resize; drag its dots to shape the intensity curve. Double-click a buzz to add a curve point (double-click a point to remove). Delete key removes the selection.

Paste the copied JSON into a file named something.ahap. Note: in Core Haptics, an intensity curve applies to the whole pattern, so avoid overlapping buzzes that use different curves.

The audio waveform appears behind the graph for alignment. Converting replaces the current pattern, which starts at 0 s to match the start of the audio. Release controls how slowly the envelope falls, Detail is the maximum number of curve points, and Threshold gates out quiet noise. Files longer than 30 s are cut to their first 30 s.
